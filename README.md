# Bot de Apoyo Gratis

Este proyecto es un chat bot sencillo de acompañamiento conversacional.
Está pensado para ofrecer un espacio de pausa, atención y claridad básica.

No es terapia, no entrega consejos médicos ni reemplaza ayuda profesional.
Si estás pasando por una situación difícil o de riesgo, busca apoyo humano
o servicios profesionales en tu país.

## Qué hace
- Permite conversar en un formato tipo terminal.
- Ofrece respuestas simples orientadas a presencia y calma.
- Funciona directo en el navegador (sin registro, sin cuentas).

## Qué no hace
- No diagnostica.
- No promete soluciones.
- No guarda datos en servidores (usa solo memoria local del navegador).

## Uso
Abre el sitio publicado en GitHub Pages y escribe en el terminal.
Ejemplos:
- Tu nombre
- “no estoy bien”
- `!help`

## Estado del proyecto
Prototipo experimental en evolución.
